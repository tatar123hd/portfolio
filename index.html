Monday research log

A personal project since August 2026. Every Monday a script runs Claude Code: it looks up current prices for five assets, writes the case for and against each one, and records a call with an exit level in a spreadsheet. I read it and make my own decisions.

Five weeks are logged so far. None of the calls have been scored yet, so this shows the reasoning, with no claim about returns.
